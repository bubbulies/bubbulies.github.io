الرسوم والصوت

التميمة «ببّي» وأيقونة التطبيق ورسوم العوالم الخمسة أعمال فنية أصلية صُنعت خصيصاً للعبة bubbulies. والفقاعات والمؤثرات ورسوم الواجهة ترسمها شيفرة اللعبة نفسها. وتُولَّد الموسيقى والمؤثرات الصوتية داخل اللعبة. لا تُستخدم حزم رسوم من جهات خارجية أو صور فوتوغرافية أو تسجيلات صوتية أو ملفات خطوط.

برمجيات مفتوحة المصدر في اللعبة

  • Phaser 3، إطار عمل اللعبة (ترخيص MIT).
  • Capacitor وإضافاته App وHaptics وPreferences (ترخيص MIT).
  • إضافة Capacitor Community AdMob (ترخيص MIT).
  • حزم Firebase لـ JavaScript ومنصات Apple (ترخيص Apache 2.0).
  • تقدّم Google حزمتي Google Mobile Ads وUser Messaging Platform بموجب شروطها الخاصة.

هذا الموقع

صفحات HTML وCSS بسيطة يولّدها برنامج Python صغير، دون نصوص برمجية أو ملفات تعريف ارتباط أو أدوات تتبع. ويستخدم الخطوط الموجودة على جهازك.
